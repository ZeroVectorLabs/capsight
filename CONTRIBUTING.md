# Contributing to Deepacket

Thanks for helping. Bug reports, captures that trip Deepacket up, and new detections are all welcome.

## Reporting a problem

Open an issue with the bug report template. A small capture that reproduces the problem is the most useful thing you can attach; strip anything sensitive first. Security problems go through private reporting instead (see [SECURITY.md](SECURITY.md)).

## Setting up

You need Node 20 or newer and Python 3.10 or newer.

```
git clone https://github.com/ZeroVectorLabs/deepacket.git
cd deepacket
npm test
npm run build
```

`npm run test:browser` runs a browser smoke test and needs `pip install playwright` plus Chromium.

## Making a change

1. Edit the files in `src/`. Do not edit `dist/deepacket.html` by hand.
2. Run `npm test`.
3. Run `npm run build` and commit the rebuilt `dist/deepacket.html` with your source change. CI fails if the bundle is stale.
4. Open a pull request and fill in the checklist.

## Adding a detection

Detections live in `src/analysis.js`. A new detection should:

- map to a MITRE ATT&CK technique,
- point at its evidence packets so the analyst can check it,
- come with a test in `tests/engine.test.mjs`,
- be added to the Detections table in the README.

In the pull request, say what normal traffic could look similar, so false positives can be checked.

## Captures

Only add captures that are generated or that you have the right to share, with no real credentials, personal data or internal addresses. The sample in `samples/` is generated by `tools/gen_attack_pcap.py` for this reason.
