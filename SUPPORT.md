# Getting help

- **How do I...?** Ask in [Discussions](https://github.com/ZeroVectorLabs/deepacket/discussions). Say what you were trying to find in the capture.
- **Something is wrong.** Open an issue with the bug report template, and attach a small capture if you can.
- **A security problem.** Report it privately, as described in [SECURITY.md](SECURITY.md).

The [README](README.md) covers the filter syntax, the detections, supported capture formats and known limitations, so it is worth a look before asking.
